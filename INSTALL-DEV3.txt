APACHE
Causa inicial do 403: AH01276; ausência de DirectoryIndex correspondente
(index.php) e listagem de diretórios desativada. A solução foi publicar o
build Node, preservando os restantes projetos.
Regras adicionadas apenas ao VirtualHost HTTPS de dev3.memogadget.com:
  ProxyPass "/tavski/assets/" "!"
  Alias "/tavski/assets/" "/home/www/dev3.memogadget.com/public_html/tavski/.output/public/assets/"
  <Directory "/home/www/dev3.memogadget.com/public_html/tavski/.output/public/assets">
      AllowOverride None
      Options -Indexes
      Require all granted
  </Directory>
  ProxyPass "/tavski/" "http://127.0.0.1:3103/tavski/"
  ProxyPassReverse "/tavski/" "http://127.0.0.1:3103/tavski/"
A exclusão dos assets deve preceder o ProxyPass geral do Tavski.
As rotas chegam ao Node; CSS e JavaScript são servidos diretamente pelo Apache.
Não foram alterados módulos nem configurações globais ou outros VirtualHosts.
Validar antes de aplicar: apache2ctl -t
Aplicar: systemctl reload apache2
O reload relê a configuração do serviço Apache inteiro.

SERVIÇO SYSTEMD
  [Unit]
  Description=Tavski DEV3
  After=network-online.target
  Wants=network-online.target

  [Service]
  Type=simple
  DynamicUser=yes
  WorkingDirectory=/home/www/dev3.memogadget.com/public_html/tavski
  ExecStart=/opt/tavski/bin/node --env-file=.env .output/server/index.mjs
  Environment=NODE_ENV=production
  Environment=NITRO_HOST=127.0.0.1
  Environment=NITRO_PORT=3103
  Restart=on-failure
  RestartSec=5
  NoNewPrivileges=yes
  ProtectSystem=strict
  ProtectHome=read-only
  PrivateTmp=yes

  [Install]
  WantedBy=multi-user.target

Ativado com systemctl enable --now tavski-dev3.service.
Não depende de SSH e não corre como root. A porta 3103 escuta em loopback.
Estado: systemctl status tavski-dev3.service --no-pager -l
Logs: journalctl -u tavski-dev3.service -n 50 --no-pager
Reiniciar apenas Tavski: systemctl restart tavski-dev3.service
O executável Node foi copiado do NVM de root; a sua atualização é separada.
